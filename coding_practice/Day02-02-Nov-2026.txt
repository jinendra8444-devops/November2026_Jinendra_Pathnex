#########
file permissions:
Read(4), Write(2), Execute(1)

There are 3 groups in a file we have
user, groups, other

all have like read, write, execute permission seperatly

By default we have 644 permissions
rw_ : user
r__ : group
r__ : other

we can change the permission using "chmod" command

chmod 777 file1 : this will give full permission 
chmod 444 file1 : this will give read permission
chmod 622 file1 : this will give RW permission for user and W permission for group and other

Like this we can set the permission of a file according to requirements

Head and Tail 

Head : this is used to fetch the top or first lines of the given file
head -30 file1  :  fetch first 30 line of file

Tail : this is used to fetch the recent lines of the given file
tail -30 file   :  fetch the last 30 lines

Note : by default it will fecth 10 line : head file1
